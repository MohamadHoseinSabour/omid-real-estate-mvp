## Key Risks

1. **Neshan Maps API:** نیاز به API key — اگر مشکلی بود، fallback به OpenStreetMap + Leaflet
2. **npm Proxy:** سیستم از پراکسی `127.0.0.1:10808` استفاده می‌کند — ممکن است نصب پکیج‌ها با مشکل مواجه شود
3. **Supabase Free Tier:** محدودیت ۵۰۰MB و ۵۰۰K Edge Function calls — برای MVP کافی
4. **RLS Complexity:** سیاست‌های دسترسی ۶ جدول × ۳ نقش — نیاز به تست دقیق
5. **RTL Edge Cases:** اعداد مختلط فارسی/لاتین، آیکون‌های جهت‌دار، جدول‌ها
