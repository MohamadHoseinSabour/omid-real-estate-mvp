# مسائل و نکات شناخته‌شده (Known Issues & Operational Notes)

> **پروژه:** MVP وبسایت آژانس املاک امید (گلستان اهواز)
> **وضعیت:** پایدار و آماده بهره‌برداری

---

## ۱. نقشه و سرویس‌های مکان‌محور (Maps)
- **وضعیت فعلی:** به جهت جلوگیری از مسدود شدن ناشی از انقضای توکن یا خطاهای CORS در پیش‌نمایش، نقشه با استفاده از کتابخانه سبک Leaflet و کاشی‌های OpenStreetMap پیاده‌سازی شده است.
- **راهکار تولید (Production):** در صورت تمایل به استفاده انحصاری از سرویس نقشه نشان (Neshan Web SDK)، کافی است کلید وب API نشان در داشبورد ثبت و اسکریپت `neshan-sdk` در تگ `<head>` جایگزین شود.

## ۲. اتصال به پروژه واقعی Supabase
- **وضعیت فعلی:** داشبورد به صورت کلاینت خودکار (با پشتیبانی از حالت شبیه‌ساز نقش‌ها) کار می‌کند تا بدون نیاز به پیکربندی فوری دیتابیس خارجی، قابل بررسی و تست باشد.
- **راه‌اندازی کامل:** فایل‌های SQL مایگریشن موجود در `supabase/migrations/` کاملاً استاندارد و آماده هستند و با اجرای آن‌ها در پروژه Supabase و ثبت متغیرهای محیطی در `.env.local`، اتصال زنده دیتابیس بلافاصله برقرار می‌شود.

## ۳. تنظیمات استقرار GitHub Pages
- **تنظیمات لازم در گیت‌هاب:** برای انتشار کامل سایت از طریق ورک‌فلو موجود (`.github/workflows/deploy.yml`)، حتماً در تنظیمات مخزن گیت‌هاب مسیر:
  `Settings > Pages > Source`
  بر روی گزینه **GitHub Actions** تنظیم گردد.
